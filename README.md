# CineVault

CineVault — локальное Windows-приложение для ведения личной библиотеки
фильмов и выбора следующего фильма через колесо с механикой выбывания.

## Статус

Версия `0.11.0-beta.1` содержит полный основной пользовательский цикл:
каталог, пользовательские списки и очереди, франшизы, колесо с сейвами, просмотренные
фильмы, оценки, статистику, историю сессий, резервные копии и импорт
CSV/TSV/XLSX, а также поиск фильмов и локальное кэширование постеров через TMDB.

Старый код сохранён в каталоге `legacy/` только как исторический референс.
Новая реализация находится в `src/`.

## Основные возможности

- фильмы, пользовательские списки, вложенные списки и франшизы;
- ручная очередь фильмов внутри списка;
- квота участников колеса для каждого списка;
- колесо в формате батл-рояля;
- персональные сейвы участников;
- просмотренные фильмы и оценки с шагом 0,5;
- история завершённых сессий;
- импорт существующей библиотеки и резервное копирование;
- поиск в TMDB с заполнением названия, года, длительности, страны, жанров,
  описания и постера;
- отдельные фильтры каталога по пользовательским спискам и жанрам TMDB;
- полностью русскоязычный интерфейс CineVault;
- светлую и тёмную темы на общей системе токенов и адаптивную мобильную
  навигацию;
- палитру команд по `Ctrl+K`: переход по разделам, быстрые действия и поиск
  по фильмам;
- выдвижную карточку фильма с описанием, метаданными и оценками;
- каталог в двух режимах — плитка и список — с фильтрами-чипами;
- сворачиваемую боковую навигацию со счётчиками разделов;
- главную страницу с hero-блоком, ключевыми метриками, лентой новых
  поступлений, очередью просмотра и коллекциями.

## Локальный запуск

На Windows при установленном Python 3:

```powershell
python launch.py
```

Лаунчер подберёт свободный локальный порт и откроет приложение в браузере.
Первый экран — витрина CineVault, кнопка «Открыть хранилище» ведёт в
библиотеку. Чтобы пропустить витрину:

```powershell
python launch.py --app
```

Прямое открытие `index.html` из файловой системы не рекомендуется, поскольку
приложение использует ES-модули и IndexedDB.

Также приложение можно запустить двойным кликом по `CineVault.cmd`.

## Подключение TMDB

Создайте API Read Access Token в настройках аккаунта TMDB, затем откройте
в CineVault раздел «Настройки» и нажмите «Подключить TMDB». Токен хранится
в `%LOCALAPPDATA%\CineVault\tmdb.json`, не показывается в интерфейсе и не
попадает в резервные копии. Загруженные постеры кэшируются в
`%LOCALAPPDATA%\CineVault\posters` и остаются доступны без интернета.

Использование API бесплатно для некоммерческих проектов при соблюдении
атрибуции TMDB. Для коммерческого использования требуется отдельная лицензия.

## Переносимая сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\build-portable.ps1
```

Скрипт создаст:

- `release/CineVault/` — чистую папку приложения;
- `release/CineVault-portable.zip` — архив для переноса.

На целевом компьютере требуется Python 3. Установка зависимостей не нужна.

## Автономная Windows-сборка

Перед первой сборкой установите зафиксированную сборочную зависимость:

```powershell
python -m pip install -r .\requirements-build.txt
```

Затем запустите упаковку:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-windows.ps1
```

Скрипт создаст `release/CineVault-Windows.zip` с единым `CineVault.exe`.
На целевом компьютере Python не требуется. При первом запуске распаковка
временных файлов может занять несколько секунд.

## Горячие клавиши

- `Ctrl+K` (`⌘K`) — палитра команд и поиск;
- `↑` `↓` `Enter` `Esc` — управление палитрой;
- `Esc` — закрыть карточку фильма;
- `Пробел` — крутить колесо в активной сессии.

## Проверка

Модульные тесты используют встроенный test runner Node.js:

```powershell
npm test
python -m unittest discover -s tests -p "test_*.py"
```

## Принцип разработки

Новые функции не добавляются непосредственно в `legacy/`. Сначала
фиксируются модель данных и бизнес-правила, затем создаётся новая версия
приложения с тестируемыми модулями.
