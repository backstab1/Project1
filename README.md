# CineVault

CineVault — приложение для ведения личной библиотеки фильмов и выбора
следующего фильма через колесо с механикой выбывания. Библиотека закреплена
за аккаунтом: витрина открыта всем, всё остальное — после входа.

## Статус

Версия `0.11.0-beta.1` содержит полный основной пользовательский цикл:
каталог, пользовательские списки и очереди, франшизы, колесо с сейвами,
просмотренные фильмы, оценки, статистику, историю сессий и поиск фильмов
через TMDB. Библиотека хранится на сервере и принадлежит аккаунту.

Старый код сохранён в каталоге `legacy/` только как исторический референс.
Новая реализация находится в `src/`.

## Основные возможности

- фильмы, пользовательские списки, вложенные списки и франшизы;
- ручная очередь фильмов внутри списка;
- квота участников колеса для каждого списка;
- колесо в формате батл-рояля;
- персональные сейвы участников;
- друзей: заявки по имени пользователя, блокировки и переключатель
  видимости библиотеки;
- просмотренные фильмы и оценки с шагом 0,5;
- история завершённых сессий;
- поиск в TMDB с заполнением названия, года, длительности, страны, жанров,
  описания и постера;
- отдельные фильтры каталога по пользовательским спискам и жанрам TMDB;
- полностью русскоязычный интерфейс CineVault;
- светлую и тёмную темы на общей системе токенов и адаптивную мобильную
  навигацию;
- палитру команд по `Ctrl+K`: переход по разделам, быстрые действия и поиск
  по фильмам;
- выдвижную карточку фильма с описанием, метаданными и оценками;
- каталог в двух режимах — плитка и список — с фильтрами-чипами;
- сворачиваемую боковую навигацию со счётчиками разделов;
- главную страницу с hero-блоком, ключевыми метриками, лентой новых
  поступлений, очередью просмотра и коллекциями.

## Аккаунт

Регистрация закрытая, по кодам приглашений: вход — почта и пароль, код из
восьми символов обменивается на профиль при создании аккаунта. Гость видит
только витрину; кнопки «Создать аккаунт» и «Войти» открывают форму отдельной
страницей. Внутри библиотеки профиль, разделы и выход собраны в кабинете —
закреплённой кнопке справа в шапке.

## Друзья и зрители

Человека находят по точному имени пользователя: списка всех аккаунтов сервис
не отдаёт. Заявку принимает адресат, отклонение и удаление из друзей просто
убирают связь, а блокировку снимает только тот, кто её поставил. Библиотека по
умолчанию скрыта — видимость для друзей включается в разделе «Друзья».

Зритель — это аккаунт: вы или принятый друг. Имена в оценках и в составе
колеса не вводятся руками, а выбираются из списка, поэтому один человек не
попадает в историю в двух написаниях.

## Хранение

Библиотека живёт в Postgres и принадлежит аккаунту: она открывается с любого
устройства после входа. Файловых выгрузок и загрузок в приложении нет — ни
JSON, ни CSV, ни импорта таблиц.

В браузере остаётся только снимок последней загрузки: он показывается на
старте, пока идёт запрос к серверу, и остаётся на экране при обрыве связи —
тогда наверху появляется полоса «нет связи», и изменения не принимаются.

Запись идёт пакетами через одну функцию Postgres: пакет применяется целиком
или не применяется вовсе. Вместе с пакетом уходит ревизия библиотеки, с
которой он собран, поэтому правка из второй вкладки или с другого устройства
не затирает чужие изменения молча — приложение предложит обновить библиотеку.

Адрес проекта Supabase и анонимный ключ лежат в `src/config.js`; порядок
настройки описан в `docs/SETUP_SUPABASE.md`.

## Локальный запуск

На Windows при установленном Python 3:

```powershell
python launch.py
```

Лаунчер подберёт свободный локальный порт и откроет приложение в браузере.
Первый экран — витрина CineVault, кнопка «Открыть хранилище» ведёт в
библиотеку. Чтобы пропустить витрину:

```powershell
python launch.py --app
```

Прямое открытие `index.html` из файловой системы не работает: приложение
использует ES-модули и ходит к серверу.

Также приложение можно запустить двойным кликом по `CineVault.cmd`.

## Данные из TMDB

Поиск фильма и заполнение карточки идут через Edge Function `tmdb`. Токен —
секрет функции, один на весь сервис: пользователю подключать нечего. Функция
отвечает только вошедшему, а расход общего токена ограничен дневной квотой на
аккаунт (300 запросов).

Постеры отдаёт CDN самого TMDB: в библиотеке хранится путь вида `/abc.jpg`,
адрес картинки собирается на лету под нужный размер. Своя обложка — отдельное
поле, и она всегда важнее постера TMDB.

Использование API бесплатно для некоммерческих проектов при соблюдении
атрибуции TMDB. Для коммерческого использования требуется отдельная лицензия.

## Выкладка

Приложение — статика: нативные ES-модули, никакого сборщика и никакого своего
бэкенда. Всё, что происходит на сервере, живёт в Supabase — Postgres, Edge
Functions и авторизация. Поэтому хостинг нужен самый простой.

```powershell
npm run build:site
```

Скрипт собирает `dist/`: `index.html`, `src/`, `assets/`, клиент Supabase из
`vendor/` плюс `_headers` с заголовками кэширования и `version.json`. Тесты,
документы, миграции и прототип в `legacy/` в выкладку не попадают.

Настройки проекта на Cloudflare Pages: команда сборки `npm run build:site`,
каталог с результатом `dist`. После появления адреса его нужно прописать в
секрет `APP_ORIGIN` функций — он ограничивает CORS.

## Резервные копии

Библиотека существует в одном экземпляре, на сервере, поэтому копии
обязательны.

```powershell
npm run backup
```

Копия снимается служебным ключом через API и ложится в
`%LOCALAPPDATA%\CineVault\db-backups` (последние четырнадцать). Она покрывает
все таблицы приложения и список аккаунтов; паролей в ней нет — их не отдаёт
никакое API, поэтому после восстановления пароль задаётся заново по ссылке из
письма. Схема базы восстанавливается не отсюда, а накатом миграций.

Восстановление в пустой проект:

```powershell
npm run restore -- <файл копии>
```

Скрипт заводит аккаунты заново по почте, переписывает ссылки на них по карте
и отказывается работать поверх непустой базы без `--force`. Весь путь целиком
— снять, потерять, вернуть — проверяется автоматически:

```powershell
npm run check:backup
```

## Горячие клавиши

- `Ctrl+K` (`⌘K`) — палитра команд и поиск;
- `↑` `↓` `Enter` `Esc` — управление палитрой;
- `Esc` — закрыть карточку фильма;
- `Пробел` — крутить колесо в активной сессии.
