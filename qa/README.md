# Visual QA

> **Проверка приостановлена.** Библиотека переехала в аккаунт на сервере, и
> прежний способ подготовки данных — `seed.html`, который наполнял IndexedDB
> прямо в браузере, — больше не работает: локального хранилища записей нет.
> Чтобы вернуть прогон, нужен демо-аккаунт на `cinevault-dev` и скрипт,
> наполняющий его библиотеку через `apply_library_changes` (как это делает
> `scripts/check-library.mjs`), плюс вход в него из `capture-visuals.ps1`.
> Задача относится к этапу 17 — см. [ROADMAP](../docs/ROADMAP.md).

Каталог `qa/` содержит воспроизводимую визуальную проверку CineVault и не
включается в пользовательскую Windows-сборку.

`capture-visuals.ps1` запускает отдельный профиль headless Edge и прогоняет
полную проверку интерфейса.

Что проверяет скрипт:

- пустую библиотеку на чистом профиле: главная, каталог, списки и колесо;
- все восемь разделов наполненной библиотеки в светлой и тёмной темах
  при 1366×768;
- мобильные размеры 390×844 и лист «Ещё» нижней навигации;
- отсутствие горизонтального переполнения и ошибок в консоли на каждом экране;
- длинное русское название не ломает карточку;
- нерабочая ссылка на постер заменяется инициалами вместо пустой рамки;
- создание, редактирование и сообщение о дубликате фильма;
- выдвижную карточку фильма с тегами и заметкой, палитру команд `Ctrl+K`;
- фильтр «Избранное» и фильтр по тегу вместе со сбросом через чип;
- сохранение и применение настроек поведения приложения;
- статусы фильма: смена в карточке сохраняется, брошенный фильм исчезает
  из пула колеса;
- режим выделения, массовое действие и очистка выделения после него;
- раздел «Статистика»: четыре состояния, графики, 12 месяцев темпа и переход
  из статуса в отфильтрованный каталог;
- отбор пула колеса по избранному и возврат к полному составу;
- выгрузка CSV с заголовком и строками;
- отмена удаления: фильм исчезает, кнопка «Вернуть» в тосте возвращает его;
- пакетное обогащение TMDB на подменённом прокси: уверенные совпадения
  применяются, спорное попадает в список ручного выбора и остаётся нетронутым;
- настройку игроков и старт сессии колеса, при котором колесо, статус,
  кнопка «Крутить» и прогресс целиком помещаются в 768 пикселей по высоте.

Запуск:

```powershell
powershell -ExecutionPolicy Bypass -File .\qa\capture-visuals.ps1
```

Скрипт завершится с ошибкой на первом же нарушении. Снимки сохраняются в
игнорируемый Git каталог `release/qa-shots` по схеме
`qa-<состояние>-<тема>-<устройство>-<раздел>.png`, временный профиль браузера —
в `release/qa-cdp-profile-<порт>`.

Лаунчер в прогоне получает временный каталог данных
(`release/qa-data-root`) через переменную `LOCALAPPDATA`: проверка не трогает
реальные постеры, токен и резервные копии на машине.

Эндпойнты `/api/tmdb/*` в прогоне подменяются заглушкой: проверка не зависит
от наличия токена на машине, не ходит в сеть и не тратит чужую квоту.

Скрипт намеренно не содержит символов вне ASCII: Windows PowerShell 5.1 читает
`.ps1` без BOM в системной кодировке, и кириллица в нём превратилась бы в
мусор.
